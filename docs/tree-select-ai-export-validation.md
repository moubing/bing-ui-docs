已精确安装 npm 正式包，正文、API、预览和 AI 导出移除本轮能力的候选提示。正式包验证包含搜索展开快照、清空恢复、活动后代语义和自定义节点高亮；面板冻结与底部占位方案已回退。详细范围见 [0.17.0 联动验证](bing-ui-0.17.0-validation.md)；下方候选说明仅记录发布前的历史状态。

## REQ-45 候选验证（2026-11-10）

本次候选复用 REQ-44 共享层，API 表更新为 41 项属性，`node` 插槽新增 `matchRanges`。正文、网页与独立示例同步 typeahead、搜索高亮、搜索展开快照、键盘光标边界、混合勾选 ARIA、标签宽度折叠和层级引导线。新增能力明确标为尚未发布，依赖和 AI 清单的 npm 版本仍为 `0.16.0`，没有发版或安装升级。

使用 `BING_UI_CANDIDATE_DIR=C:/workspace/bing-ui` 指向本地构建产物验证；浏览器均为系统 Chrome 无头模式。文档页 10 项测试通过，包含 1440/390px 深浅色、代码复制、虚拟树、状态保留和离场清理。独立示例与阅读应用 14 项测试通过，新增搜索内收起/恢复、活动后代和自定义高亮验证。

`docs:check tree-select`、文档/测试 TypeScript 检查通过；TreeSelect 的 5 个导出示例与 1 个阅读应用通过严格类型检查。既有测试按候选契约改用 combobox、aria-checked 和仅可见标签计数，展开按钮通过节点内选择器操作。既有单选、级联、严格模式、禁用父节点和多实例 Dialog 回归继续通过。

合入主分支前，自定义节点示例为尚未提供 `matchRanges` 的发布包补齐空数组默认值。无头浏览器分别验证 `0.16.0` 下正常打开与搜索，以及候选版本的插槽高亮；AI 导出一致性、文档/测试类型检查和 6 个导出 SFC 类型检查再次通过。

## 早期迁移记录

适用 `@moubing/bing-ui 0.5.3`。五个完整 SFC 覆盖基础选择、多选级联、自定义节点、虚拟树和弹层定位；命令为 `pnpm docs:export tree-select`。六张 API 表包含 39 项属性、8 个节点字段、3 个插槽、7 个事件、公开类型及推导方式、平滑滚动配置。

- 所有树数据、回调和样式完整内置；网页代码与 AI 导出共用这些示例。虚拟树包含 28 个父节点、392 个子节点。原来未导出的弹层位置和对齐类型改为从 Props 推导；布尔与数值选项保持实际类型。
- 核对级联补齐父子节点、严格模式互不影响、未知值和禁用值归一化、数字与字符串区分。归一化不会主动回写外部模型，下一次操作才输出新值；事件载荷含完整已选节点。
- 阅读应用验证搜索只显示匹配父节点时，批量选择仍可包含未显示的子节点；清空当前结果保留范围外值。触发器清除、父 Tag 删除和单节点选择的范围与事件顺序分别验证。
- 核对默认展开只在初始化读取、全部展开不发送单节点事件、defaultExpandAll 切回 false 不收起，以及禁用父节点的子节点仍可选。实际键盘定位和虚拟末节点选择通过。
- 文档明确详情浮层可能遮住侧栏，操作前可移出节点等待详情关闭；不宣称修复组件内部重复 ID、无障碍或窄屏浮层限制。首次测试中的模板空格与打开后自动聚焦时机已按实际界面调整，未绕过真实选择逻辑。
- 网页预览在缓存离开时卸载，清理浮层与监听，返回保留模型。控制组使用明确标签、唯一 id/name 和可换行布局，长级联值反馈也可在窄屏换行。
- 网页 9 项、独立导出/阅读应用 11 项无头用例全部通过；另通过 2 项 Form/FormItem 往返、目录、system 主题和 Tabs/Table 页面回归。四张明暗宽窄截图与窄屏面板截图已检查。
- 全部 33 个组件生成一致性、74 项导出测试、文档/测试类型检查通过；141 个导出 SFC 与 31 个阅读应用，共 172 个文件通过严格类型检查。布局的两处数组取值已有非空检查，补充类型断言后全站 Nuxt 类型检查也通过。未运行完整构建。
- 阅读应用由同一助手根据导出重组，不是独立模型盲测。迁移结束时临时浏览器与服务退出，截图、trace 和迁移辅助文件移入回收站，当时保留正式截图基线。后续统一测试策略时已移除固定基线，当前规则见 [README](../README.md#验证)。
