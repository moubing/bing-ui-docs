## 用法说明

- 独立 Checkbox 使用布尔模型；`indeterminate` 由业务计算，没有 `update:indeterminate` 事件。状态示例中的固定半选参数只展示初始外观。
- 放入 CheckboxGroup 后为子项指定唯一 `value`，从 Group 监听数组变化；有 value 的组内子项不会单独发出 change/update:modelValue。
- `change` 接收布尔值和原始 Event 两个参数。装饰模式输出隐藏于辅助技术的只读标记，不生成 input，也不承担表单或键盘交互。
- 页面四个 RadioGroup 控制组显式设置不同的 ID/name，避开 0.5.3 的默认名称重复问题。
