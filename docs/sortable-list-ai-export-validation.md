# SortableList 迁移验证

适用 `@moubing/bing-ui 0.5.3`。四个完整 SFC 包含基础排序、禁用与手柄、横向排序、外部受控顺序，命令为 `pnpm docs:export sortable-list`。五张表覆盖 15 项属性、默认插槽、手柄结构、5 个事件与 11 个公开类型。

- 数据、回调和必要样式完整内置。示例使用稳定 id 解析函数；去除可聚焦拖拽手柄上的 aria-hidden，并为每个手柄提供项目名称。受控示例代码移到章节直接子级，与其他示例使用同一复制/导出流程。
- 验证归一化删除未知键、去重并补回遗漏键，但不主动回写外部 order；items 本身不会重排。明确回调的源索引与当前渲染索引不同。
- 真实指针拖动验证 drop/live 的更新时机，以及取消 drop 保持原值、取消 live 保留已提交值且不发 drag-end。拖动时存在临时镜像，测试按 drag 载荷检查投影，释放后检查实际 DOM 顺序。
- 验证禁用项不能发起操作，但其他项仍可使它移动；原“固定开头”的说明已纠正。补充方向键直接提交、整卡手柄、受控更新被忽略和动画边界。
- 网页缓存离开时卸载预览以清理拖拽管理器、监听与动画，返回保留业务顺序。
- 70 项导出测试、导出一致性、文档/测试类型检查通过；131 个完整导出 SFC 与 29 个阅读应用，共 160 个文件通过严格类型检查。全站仍为布局和 TreeSelect 的原有 4 项诊断，未运行完整构建。
- 网页 7 项、独立导出/阅读应用 9 项无头用例通过。四张明暗宽窄截图已检查。阅读应用由同一助手根据导出重组，不是独立模型盲测。
- 临时浏览器和服务退出，截图及 trace 移入回收站。
