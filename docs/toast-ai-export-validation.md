# Toast 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/toast.md`，共享 API 包含 7 项属性、9 项消息选项、11 行服务说明（含两个 error 别名及 useBingToast）、1 个事件、5 项公开类型和 11 项消息字段。四个完整示例为基础调用、消息类型、loading 替换和位置；命令为 `pnpm docs:export toast`。

- 保留原有 URL、章节与预览控制，新增公开类型章节；网页代码复制和 AI 导出共用完整 SFC，补齐原来缺失的组件导入、状态、处理函数与样式。
- 核对包实现并说明：useBingToast 与 bingToast 共享服务；同 id 更新是整条替换，保留 createdAt/order；show 保留传入 type；数字 id 转字符串。补齐全部默认持续时间、位置别名、max 不裁剪和浅拷贝限制。
- 说明新增或更新消息会重启整个队列计时，悬停或聚焦会暂停队列，离开后从完整 duration 重新开始。close 事件只来自关闭按钮，事件发出后才移除消息。
- loading 独立示例取消自己的定时器，更新前确认消息仍存在，防止用户关闭后再次弹出。网页演示同时处理重复点击、清空队列、异步位置参数快照和离页取消。
- 页面往返测试发现站点启用了 KeepAlive：旧页面未卸载，Teleport 视口仍存在，最先注册的视口持续占用全局消息显示权。新增 DocsToastViewport 在停用时卸载真实视口，在激活时重新挂载；Toast、Button 示例及首页统一使用它。Toast 页面在 onDeactivated 时清理自己的消息和任务，保留缓存的表单控制状态。
- 导出一致性、42 项导出测试、文档及测试类型检查通过；17 个组件的 74 个导出 SFC 和 15 个阅读应用用例，共 89 个文件通过严格类型检查。
- 网页 7 项无头用例通过：1440/390px 明暗主题、章节/API、四份代码复制、创建与关闭、loading 更新，以及 Toast → Button → Toast → 首页 → 快速开始 → Toast 的缓存页面往返。离页任务不再弹出消息，活动视口只有一个，返回后仍能创建提示。四种布局截图已检查。
