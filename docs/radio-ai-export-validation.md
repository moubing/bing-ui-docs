# Radio 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/radio.md`，11 项属性、2 个插槽与 4 个事件共用 `shared/docs/radio.ts`。四个独立示例覆盖基础配置、尺寸状态、组内插槽和事件；命令为 `pnpm docs:export radio`。

## 迁移与用法

- 原有 URL、章节、四个预览和参数交互保留。基础代码跟随页面配置变化；网页复制结果与 AI 导出一致。
- 补齐示例导入、状态、事件参数和样式；尺寸状态示例与预览一致地共用一个模型，组内示例包含全部三个选项。
- 模型与 value 严格比较，明确字符串、数字、布尔值以及 null 的区别；再次点击已选项不会反选。
- 组内只绑定 Group 的模型并监听其 change；独立 Radio 的 change 接收值和 Event 两个参数，不能从原生 input 的字符串 value 推断模型类型。
- 0.5.3 的 Radio 自动 ID 在多实例间重复，Group options 生成的子项也受影响。当前页面及独立示例的 Radio 显式指定唯一 ID；页面两个控制组采用默认插槽并保留统一 name，视觉样式不变。未修改组件包。

## 验证

- 导出一致性、20 项导出测试、文档与测试类型检查通过；7 个组件的 27 个导出 SFC 与 5 个阅读应用用例共 32 个文件通过严格类型检查。
- 网页 6 项浏览器测试通过：明暗主题、1440/390px、章节/API、横向溢出、代码复制、动态 value、各组独立选中、禁用、事件重置和页面 Radio ID 唯一性。四张预览截图已人工检查。
- 独立示例 4 项浏览器测试通过，覆盖四个导出文件与新阅读应用用例。新用例验证数字 0、字符串 "0"、false、null 的区分以及主文案和描述插槽；这是同一助手的阅读应用检查，未做独立模型盲测。
- 首次网页复制测试在 SSR 外壳出现时过早点击，验收工具已改为等待 ClientOnly 预览挂载，再操作真实剪贴板。
- 全站类型检查仍有既有 15 项错误，无 Radio 新增错误。未运行完整构建，临时截图与测试进程已清理。
