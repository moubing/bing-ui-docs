## 阅读与应用核对

同一助手读取导出结果并核对发布包类型、运行实现及浏览器行为，未进行独立模型盲测。

| 问题 | 文档提供的答案及验证 |
| --- | --- |
| Tabs 是否内置内容面板？ | 没有，示例按 `v-model` 渲染业务内容；点击和方向键切换后面板正确更新。 |
| manual 模式中焦点和选中值是否相同？ | 不一定；方向键、Home、End 移动焦点，Enter/空格确认。浏览器验证确认前选中值不变。 |
| 禁用项和边界如何处理？ | 禁用项不能点击且被键盘跳过；`loop=false` 到达边界后不循环。 |
| 自定义 `tone/count` 能否直接当强类型字段？ | 插槽业务字段是 `unknown`，示例通过类型缩窄后用于样式和数量。 |
| `change` 是值还是对象？ | 是含 value、item、前值及原始事件的对象；前值和前项可缺省，正文补充了完整类型。 |
| 严格模板能否识别组件的名称属性？ | 示例使用声明中的 `ariaLabel`，运行后生成正确的 tablist 可访问名称。 |
