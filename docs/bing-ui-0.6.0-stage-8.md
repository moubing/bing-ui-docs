# Bing UI 0.6.0 文档更新：第八阶段

日期：2026-09-12。对应[更新计划](bing-ui-0.6.0-update-plan.md)的入口与全站收尾阶段。

## 交付

- 首页同步新版中性色、炭灰暗色、细边框、轻阴影与较轻字重，保留原有页面结构、交互场景和真实动效。版本号与组件数量来自共享状态，安装命令明确组件版本和 GSAP 依赖，精选组件补入 Cursor。
- 首页交互卡片改为 `examples/home/showcase.vue` 完整 SFC，网页直接使用该示例并复制同一份源码，包含显式组件及样式导入、翻面状态和键盘操作。代码区限制显示高度，通过内部滚动阅读完整内容。
- 首页配色同步成组语义变量与前景对比色；窄屏调整颜色控件宽度、代码区收缩、安装命令换行和结尾标题。KeepAlive 停用时结束首页动画、卸载演示并清理反馈状态。
- 快速开始改为面向组件使用者的安装、样式导入、Vue/Nuxt 接入、主题与尺寸说明，移除占位及文档维护约定。保留 `overview / usage / themes / api` 锚点，新增 Nuxt 和尺寸章节。
- 新增[0.6.0 升级指南](../content/guides/upgrade.md)，通过 `/docs/upgrade` 渲染并接入原有导航。说明 Button 节流、Input 模型与清除行为、Form 默认校验及新属性，以及样式、浮层、转场与 Cursor 的迁移边界。
- README、AI 文件头、`llms.txt` 与版本清单统一到 r8。保留 0.5.3 的历史验证记录，增加当前版本结论的入口。

当前共 34 个已验证组件、154 个组件独立示例、35 个阅读应用用例；首页另有 1 个完整示例。清单的待验证和待新增组件均为空。清单保留原有 `status: experimental` 字段值及空历史版本列表；逐组件验证状态均为 `verified`。

## 验证

入口专项已验证首页版本、组件导航、安装命令和完整卡片的实际剪贴板、配色、排序、键盘翻面、Toast，以及快速开始的包管理器、Nuxt 配置、升级指南、system 主题和页面往返。

首轮发现并修正窄屏预览区的颜色选择器宽度；测试在快速开始交互前等待 Nuxt 水合完成，避免点击服务端静态外壳。人工查看首页与交互场景的浅深主题、390px 代码卡片与结尾区域，以及快速开始和升级指南。

Nuxt、文档与测试 TypeScript 检查通过。34 个组件导出的示例与阅读应用共 189 个 SFC 严格检查通过；78 项导出测试及 `docs:check` 通过。升级指南中的组件路由与锚点已逐项核对。

站点全量 265 项浏览器检查通过（8.3 分钟）。收尾补充首页卡片空格键翻面时保持滚动位置的检查，连同实际代码复制、配色和排序复验通过。独立导出示例与阅读应用全量 231 项浏览器检查通过（2.3 分钟）。最后的 Nuxt 与测试 TypeScript 检查再次通过。

## 适用范围

验证基于实际安装的 `@moubing/bing-ui@0.6.0`。本轮更新文档仓库，未修改组件库；剩余的 FilePreview 跨分支滚动锁、转场离屏焦点与动态列表、Carousel 禁用项滚轮等边界已在对应组件正文和升级指南中说明。

八个阶段分别保留本地提交。本阶段不推送、不部署；浏览器使用临时环境变量选择系统 Chrome 无头模式，没有运行完整构建或更新像素快照。
