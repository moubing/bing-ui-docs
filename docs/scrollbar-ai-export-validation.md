# Scrollbar 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/scrollbar.md`，共享 API 包括 11 项属性、9 项平滑选项、1 个事件和 6 个实例成员。四个独立示例为基础、横向、平滑与原生对照、实例方法；命令为 `pnpm docs:export scrollbar`。

- 保留原有 URL、章节、控制区；平滑配置章节增加可操作对照预览，实例预览补充外部滚轮、停止插值和追加后更新。网页复制与 AI 导出共用完整 SFC，包含必要样式与导入。
- 对照本地组件实现，修正轴开关不关闭原生 overflow、禁用仍允许程序定位、显式名称不要求溢出、最小容差以及公开平滑配置类型。
- 明确 `stop()` 取消组件插值，不取消浏览器原生 smooth 动画；`smooth=false` 仍保留横向 Shift+滚轮兼容处理。外部滚轮不无条件 preventDefault，异步内容更新后先 nextTick。
- 导出一致性、40 项导出测试、文档及测试类型检查通过；16 个组件的 70 个导出 SFC 和 14 个阅读应用用例，共 84 个文件通过严格类型检查。
- 网页 6 项无头测试通过，覆盖明暗主题、1440/390px、章节和 API、四份完整代码复制、滚动反馈、禁用、定位、追加内容。四张最终截图已检查，无页面横向溢出。
- 独立导出 5 项无头测试通过，覆盖四个文件，验证键盘滚动、事件读数、轨道拖拽、Shift 横向滚动、平滑与原生纵向输入、数字与对象定位、追加更新、外部滚轮消费和停止组件插值。
- 阅读应用验证关闭轨道后仍可原生滚动、短内容仍有 region 名称、禁用后实例方法仍可定位。由同一助手阅读生成文档后编写并核对，没有独立模型盲测。
