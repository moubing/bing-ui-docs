# Bing UI 0.6.0 文档更新：第二阶段

日期：2026-09-12。对应[更新计划](bing-ui-0.6.0-update-plan.md)的公共视觉与样板阶段。沿用现有路由、导航条目、Markdown 结构和原有锚点。

## 公共视觉与布局

- 站点背景、表面、文字、边框、强调色、阴影及选择色映射到组件库语义变量，浅色、深色和 system 共用同一套定义。
- 调整标题、正文、代码、提示块、示例容器和参数面板的字重、字号及间距；移除旧 Dialog 遮罩的三个内部样式补丁，代码区使用库自身排版。
- 宽屏保留侧栏、正文、目录三列；窄屏将组件导航收起为可展开目录，支持 Escape 返回按钮，点击链接后收起。页面导航顺序保持不变。
- API 表格保留局部横向滚动，并提供键盘焦点和区域名称。Header 在大字体下允许换行，避免主题按钮被裁切。
- 浏览器测试共用 `navigateToDocs`，按真实窄屏导航方式切页；没有通过隐藏链接绕过目录交互。

## 四个组件的变更与验收

| 组件 | 内容与示例 | 核对的主要行为 |
| --- | --- | --- |
| Button | 更正 throttle=false、五档高度、表单继承、loading 文字；节流示例显式开启，扫光默认继承主题、自定义配色可选 | 默认连续点击、显式节流、加载和禁用、文字效果、原生表单、无文字命名、表单继承与覆盖 |
| Input | 更正模型联合类型、清除默认值、中文按钮和 autocomplete；新增数值、只读与平滑光标两个完整示例 | 数字 0、小数步进、上下界、键盘、null 和清空、事件类型与顺序、防抖取消、选区、只读、光标开关及减少动态效果 |
| Select | 更新中文默认文案、尺寸与虚拟行高、主题磨砂和实例 ID；虚拟演示留空时使用默认行高 | 单/多选、搜索、结果全选边界、末项键盘定位、参数代码同步、唯一 ID、浅深磨砂、窄屏、弹窗内焦点及 Escape、切页清理 |
| Card | 更新主题磨砂默认值和单层表面说明，保留当前反面可访问性限制；网页详情按钮与独立示例行为对齐 | 入场、翻面、长按恢复与移动取消、业务按钮隔离、disabled 边界、减少动态效果及浅深磨砂 |

Input 的独立示例从 5 个增加到 7 个，全站独立示例从 141 个增加到 143 个。新增网页预览直接复用完整 Vue 示例，避免两份运行逻辑漂移。

四个组件都已完成 API/正文、网页预览、独立示例、AI 导出和验证五项记录。AI 已验证覆盖为 4 个，其余 29 个现有页面保持迁移提示，Cursor 仍列为待新增。

只使用系统 Chrome 无头模式与进程级环境变量；没有提交机器专属配置，没有运行完整构建或更新像素快照。

## 保留的边界

- Card 反面在 0.6.0 仍带 aria-hidden，关键内容需普通正文或按钮入口。
- Select 详情浮层仍用于视觉补充；没有增加库未公开的实例方法或远程搜索能力。
- 输入框手动录入的越界数字仍需业务或表单校验，步进约束不等于自动截断所有输入。
- 第一阶段被自动审批拒绝的临时文件仍列在升级基线的清理待办中。

本阶段测试服务已经关闭，3107、3108、3110、3111 无监听。删除本阶段九个 `test-results/stage2-*` 目录前已限定并校验路径范围，但自动审批拒绝执行，原因仅为 `blocked by policy`。未重试其他删除方式；这些目录仍保留且不纳入提交：`stage2-site`、`stage2-ai`、`stage2-layout`、`stage2-select-card-ai`、`stage2-ai-recheck`、`stage2-shell-recheck`、`stage2-shell-verified`、`stage2-navigation-final`、`stage2-final`。
