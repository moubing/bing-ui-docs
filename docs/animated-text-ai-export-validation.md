## 历史验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/animated-text.md`，共享 API 包含 16 项属性、默认插槽和 4 个公开类型，补齐原文遗漏的 shineDelay。四个完整示例为效果选择、扫光配置、字符跳动和禁用扫光；命令为 `pnpm docs:export animated-text`。

- 保留 URL、章节、原预览和控制区，网页复制与 AI 导出共用完整 SFC。补全组件/样式导入和演示配置，文字明确通过默认插槽传入，options.text 不是组件属性。
- 核对扫光速度下限、首轮/hover 延迟、循环间隔和方向，以及 jump 的位移、错峰、时长和回落比例。说明 once 不等待进入视口，hover 只接收 mouseenter，不提供 focus/click 激活或公开播放方法。
- 阅读用例复现当前组件播放中的 jump 会跳过重建：仅修改 disabled 后旧循环仍存在。基础与跳动示例用包含文字及相关参数的 key 重建实例，避免变化后遗留旧动画和拆字；这属于文档示例处理，没有修改组件包。
- 禁用示例演示 shine 清理与重新开始，不表示进度暂停。说明减少动态效果在初始化/播放时检查，没有监听偏好变化来立即取消既有 jump。拆字的 aria-label/aria-hidden 行为、短纯文本建议和交互元素边界已写入正文。
- 三个 Radio 控制组使用唯一 ID/name；缓存页面停用时卸载预览及控制区，清理循环和颜色选择浮层，切回保持配置并重新挂载。
- 导出一致性、56 项导出测试、文档/测试类型检查通过。24 个组件的 102 个导出 SFC 与 22 个阅读应用，共 124 个文件通过严格类型检查。
- 网页 7 项用例通过，覆盖 1440/390px 明暗主题、章节/API、四份代码复制、文字/效果/禁用切换、扫光方向、跳动参数和缓存页面卸载。定位器收窄到实际预览后复测交互用例，排除复制按钮内部同名组件；四张布局和一张跳动控制区截图均已检查。
- 独立导出和阅读应用 8 项无头用例通过，覆盖四份示例、真实字符位移、完整一轮、Unicode 字符拆分、key 重建、无 key 的实际限制、once、延迟扫光、卸载及减少动态效果。阅读应用由同一助手根据导出文档重组，没有独立模型盲测。
- 全站类型检查仍为原有 6 项诊断，本组件没有新增错误；未运行完整构建。临时服务和浏览器已退出，截图与 trace 移入回收站。
