# Resizable 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/resizable.md`，共享 API 包括 18 项属性、方向、插槽、事件、实例方法及 7 项参数结构。五个独立示例为基础、固定/镜像、约束、实例方法和新增受控模式；命令为 `pnpm docs:export resizable`。

- 保留原有章节和控制区，增加受控示例及参数类型章节，网页复制与 AI 导出共用完整 SFC。
- snapMode 从公开 Props 提取类型，替代未公开导出的类型名。修正受控临时预览、更新事件顺序、默认值重置、Escape 提交及比例锁定仍保留角手柄等说明。
- 明确 contain 不主动修正初始尺寸，边界裁剪可能破坏比例；最小尺寸大于容器时也无法保证放入。使用像素数字避免 CSS 单位与 parseFloat 状态不一致。
- 基础预览增加“应用初始尺寸”；预览画布提供独立横向滚动，窄屏仍能访问右侧手柄。比例示例为最大尺寸预留空间。
- 导出一致性、38 项导出测试、文档与测试类型检查通过；15 个组件的 66 个导出 SFC 与 13 个阅读应用用例，共 79 个文件通过严格类型检查。
- 网页 7 项无头测试通过，覆盖明暗主题、1440/390px、章节/API、完整代码复制、键盘步长、重置、全部手柄、禁用和窄屏手柄操作。四种最终截图已人工检查。
- 独立示例 5 项无头测试覆盖所有五个文件及阅读应用用例，验证鼠标拖拽、Escape 提交、Shift 步长、镜像位置、松手吸附、尺寸与位置受控同步、ref 读数和重置。
- 阅读应用验证未同步的受控值回退、真实事件顺序、约束冲突改变比例、操作后修改默认值需重置。用例由同一助手编写，未做独立模型盲测。
- 全站类型错误由 9 项降至 8 项，无 Resizable 新增错误。未运行完整构建；临时测试文件与进程已清理。
