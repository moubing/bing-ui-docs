## 0.5.3 历史记录

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/textarea.md`，19 项属性、6 个事件及 4 项实例接口共用 `shared/docs/textarea.ts`。五个独立示例为基础、自动高度、布局状态、事件和实例方法；命令为 `pnpm docs:export textarea`。

## 迁移与修正

- 保留原有 URL、章节、五个预览和控制区；网页与 AI 使用相同完整 SFC，基础代码随参数变化。
- 补齐文本模型、事件的两个参数、所有组件导入和 ref 方法。三个布局状态预览由固定 model-value 改为各自的 v-model，输入与清除可正确更新状态。
- select 反馈改为读取原生 textarea 的实际选区，避免仅显示外部文本而掩盖方法是否生效。
- 0.5.3 动态关闭 autosize 时不会清理行内高度；页面切换模式时使用 key 重建控件，外部文本保持。此限制已写入正文，没有修改组件包。
- 明确清除不触发 input、模型不能为 null、字符统计采用字符串 length、maxLength 不截断程序赋值。页面五个 RadioGroup 控制区使用唯一 ID/name 和显式子项。
