## 历史验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/tooltip.md`，共享 API 包含 21 项属性、2 个插槽、3 个事件、4 个实例方法及 5 项公开类型。完整示例为基础交互、富内容、四向定位和手动控制；命令为 `pnpm docs:export tooltip`。

- 保留原 URL、章节和控制区，补齐原来仅有片段的导入、模型、事件、插槽行为与样式，新增公开类型章节。网页代码复制与 AI 导出共用四个 SFC。
- 对照包实现修正玻璃默认值、触发数组、对齐轴、外部 pointerdown、状态事件与方法签名。显式模型需要同步更新；多个实例共享浮层，失去显示权不清除原模型，也不一定触发 close，实际可见性使用默认插槽 open。
- 验证 disabled 不清除受控 true 值，重新启用可再次显示；实际 close 原因为 manual，不能假定总是 disabled。说明初始 modelValue=true 不发送初次 open，外部变更默认为 manual 原因。
- 默认 ARIA 关系落在外层 span，网页预览显式关联实际按钮。独立示例使用原生按钮直接绑定 aria-describedby，避免依赖 BingButton 未声明的属性；继续保留 Bing UI 控件演示内容操作和实例方法。
- 手动外部切换示例关闭 closeOnOutside，避免 pointerdown 先关闭、click 又打开。纯文本定位例设置 interactive=false，避免提示遮挡相邻按钮。控制区使用唯一 Radio ID/name，位置和对齐选项可换行，四种最终截图已检查。
- 缓存页面停用时卸载预览 Tooltip 并清空打开状态；返回后保留参数配置，避免共享浮层与计时任务留在隐藏页面。
- 导出一致性、44 项导出测试、文档及测试类型检查通过；18 个组件的 78 个导出 SFC 和 16 个阅读应用用例，共 94 个文件通过严格类型检查。
- 网页 7 项无头用例通过，覆盖 1440/390px 明暗主题、章节/API、四份代码复制、按钮提示关联、触发方式、富内容、手动开关及缓存页面往返。布局调整后重新检查四张截图和代码复制。
- 独立导出及阅读应用 7 项无头用例通过，覆盖点击/Escape/outside、内容操作、共享浮层、实例 show/hide/toggle/updatePosition、受控值未同步、禁用保留模型、悬停取消与延迟关闭、聚焦打开及窄屏边缘翻转。位置断言允许最多半个设备像素的坐标舍入差。
- 阅读应用由同一助手根据导出内容编写并核对，没有独立模型盲测。全站类型检查仍为原有 8 项错误，本轮没有新增诊断；未运行完整构建。测试后关闭临时服务和浏览器，截图与 trace 清理至回收站。

## 短提示额外留白修复（0.9.1，2026-10-02）

- `0.9.0` 的 Tooltip 同时启用横纵滚动条，内容内边距之外又预留了右侧、底部各 13px 的轨道空间。两字“斜体”的面板高度实测为 45px，文字没有发生换行。
- 组件源码让轨道复用提示框已有内边距，总间距保持上下 6px、左右 8px；短提示恢复为 42×32px。只调整 Tooltip 自身的间距分配与横向轨道位置，不改变通用 Scrollbar 的固定占位规则。
- 基础网页和独立示例默认改为“斜体”，正文、API 与 AI 导出同步说明短提示尺寸及修复版本。
- Tooltip/Scrollbar 的 33 项单元测试及 Tooltip 的 9 项无头浏览器测试通过，覆盖短文案、横向宽内容、纵向长内容、共享面板切回短提示和四向箭头。无头 Edge 检查浅色、深色的实际短提示截图，均无额外空白或页面错误。
- 发布前组件库完整验证通过：460 项单元测试、231 项无头浏览器测试及构建。npm 已发布 `0.9.1`，`latest` 指向该版本；文档项目精确安装发布包并重新生成全部 AI 导出。
- 文档的 80 项导出测试、导出一致性、API/测试类型检查及全部 192 个独立示例/阅读 SFC 的严格类型检查通过。Table、Tooltip、Input、Autocomplete 共 61 项无头浏览器用例通过；其中 Tooltip 有 8 项独立示例和 7 项网页用例，均加入两字提示高度为 32px 的检查。其他组件沿用已有行为验证，本次追加全量导出与示例类型检查。
- 业务 worktree 安装 `0.9.1` 后，用真实 `RichRequirementEditor`、应用字体和样式完成无头组件集成验证：浅色、深色“斜体”提示均为 32px 高，点击工具后仍能输入斜体正文，无页面错误。测试替换 NuxtLink 与阅读位置状态，没有连接业务服务端。
