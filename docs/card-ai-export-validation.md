# Card 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/card.md`，25 项属性、5 个插槽与 3 个事件共用 `shared/docs/card.ts`。六个完整示例包括基础、视觉类型、入场配置、预设对比、翻面和插槽；命令为 `pnpm docs:export card`。

- 保留原有六组预览、URL、章节和配置交互；为原来只有预览的入场预设对比补充独立代码。网页与 AI 共用六个 SFC。
- 从公开 BingCardProps 提取 flipTrigger 类型，替代包入口未公开导出的类型名。玻璃默认值展开为 16、0.85、1.28，glassBlur 修正为 string | number。
- 补齐事件处理与样式，操作按钮停止事件冒泡。说明 flip/enter 的通知时机、长按最小等待与移动取消、z 轴回退、interactive 的实际范围。
- 明确现有包的可访问性限制：反面始终 aria-hidden，卡片没有键盘翻面语义；关键说明另提供普通正文与按钮入口。
- disabled 会阻止卡片表面指针事件，但不会设置子按钮 disabled，键盘仍可能激活子按钮；完整示例需要时显式禁用子控件。没有修改或发布组件包。
- 导出一致性、36 项导出测试、文档与测试类型检查通过；14 个组件的 61 个导出 SFC 与 12 个阅读应用用例，共 73 个文件通过严格类型检查。
- 网页 6 项无头测试通过：明暗主题、1440/390px、章节/API、完整代码复制、标题参数、翻面和入场重建。测试增加可选准备步骤，让依赖进入视口的卡片先滚动到可见区域；截图增高后重新定位，避免滚动容器裁切。四种最终截图已人工检查。
- 独立示例 3 项无头测试覆盖全部六个文件及阅读应用用例，验证插槽替代、业务按钮、重新挂载入场、点击翻面、长按恢复与移动取消、interactive/disabled 边界及可访问详情入口。
