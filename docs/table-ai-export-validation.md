# Table 迁移验证

适用 `@moubing/bing-ui 0.5.3`。五个完整 SFC 覆盖基础表格、树形行、列配置、虚拟列表和实例方法；命令为 `pnpm docs:export table`。七张 API 表包含 56 项属性、17 个列字段、插槽、20 个事件、实例方法、23 个公开类型与平滑滚动参数。

- 数据、列定义、回调和样式完整内置；网页代码区与 AI 导出共用这些文件。树形示例使用自己的展开状态，网页缓存离开时卸载预览，返回保留业务状态。
- 核对顶层排序、按根节点分页后展开子行、远程分页仍执行本地排序，以及分页大小变化时回到第一页。选择父行不会级联选择子行；全选作用于当前页展开后的可选行，虚拟列表未挂载的行也在范围内。
- 阅读应用验证未知选择键保留但对应行不出现在事件 rows 中、当前数据不包含远程其他页行、列重置只重置列状态。受控模型、默认值、列宽解析和固定列分组均补充了实际边界。
- 实例滚动测试发现原示例 `max-height="280"` 是没有 CSS 单位的字符串，不能形成预期高度限制。所有示例中的此类高度统一改成数值绑定，实际滚动通过。
- 无头检查列宽调整、显示隐藏、固定列、重置、分页、选择、展开与虚拟滚动。四张明暗宽窄截图和窄屏列面板截图已检查。390px 下两侧固定列可能挤占中间列，文档说明可减少固定列或取消固定；未把组件本身的限制描述为迁移已修复。表头拖拽运行时覆盖了 th 的角色，也没有宣称完整的表格无障碍支持。
- 72 项导出测试、生成一致性、文档/测试类型检查通过；136 个完整导出 SFC 与 30 个阅读应用，共 166 个文件通过严格类型检查。全站仍为布局和 TreeSelect 的原有 4 项诊断，未运行完整构建。
- 网页 7 项、独立导出/阅读应用 8 项无头用例全部通过。阅读应用由同一助手根据导出重组，不是独立模型盲测。
- 临时浏览器与服务退出，截图及 trace 移入回收站。

## 表头禁用光标修复（0.9.1，2026-10-02）

- `0.9.0` 在 `reorderableColumns=false` 时仍注册表头拖拽，拖拽库将整个 `th` 标记为 `aria-disabled=true`，导致 `BingCursor` 在表头及排序按钮上显示禁用光标。
- 组件源码改为关闭拖拽时渲染普通 `th`，保留列键、样式、插槽和排序按钮；启用拖拽时沿用拖拽表头。不修改全局光标的禁用判断。
- 正文、API 说明、网页列设置示例、独立示例与 AI 导出同步记录此问题；示例使用局部 `BingCursor`，网页可切换“允许拖动列顺序”。
- 发布前组件库 460 项单元测试、231 项无头浏览器测试与构建通过。新增回归覆盖初始关闭、重新启用、再次关闭、普通表头语义、默认/抓取/手形光标与真实点击排序。
- npm 已发布 `0.9.1`，`latest` 指向该版本；文档项目精确安装发布包，重新生成全部 AI 导出。80 项导出测试、导出一致性、文档 API/测试类型检查及全部 192 个导出/阅读 SFC 的严格类型检查通过。
- 安装 `0.9.1` 后，Table、Tooltip、Input、Autocomplete 的 31 项独立示例和 30 项文档站无头用例通过；其中 Table 有 12 项独立示例和 9 项网页用例，新增网页回归直接验证关闭列拖拽后的语义、光标与升降序切换。其他组件沿用已有行为验证，本次追加全量导出与示例类型检查。
