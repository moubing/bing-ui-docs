# DropDown 迁移验证

## 0.18.3 右对齐定位修复（2026-11-11）

0.18.2 的普通元素锚点返回原生 DOMRect；定位函数展开对象时遗漏原型访问器上的 width/height，导致 bottom-end / top-end 横坐标和 left-end / right-end 纵坐标失效。0.18.3 显式读取这两个尺寸，公开 API 不变。

正文和 placement API 补充 end 对齐及边缘避让语义，网页与独立基础示例默认展示右侧按钮的 bottom-end，网页控制区提供全部八种方向。文档、看板依赖和 AI 导出已精确升级至 0.18.3，DropDown 标记 verified。

发布前通过 `BING_UI_CANDIDATE_DIR` 接入已核验的组件仓库构建；发布后移除候选环境变量，再使用正式 npm 包回归。验证结果：

- 组件库 70 个单元测试文件 / 773 项测试、39 个浏览器测试文件 / 473 项测试及构建通过；其中 DropDown 26 项浏览器测试包含原生 DOMRect 的四个 end 方向、窗口尺寸变化、虚拟锚点、局部边界、键盘与子菜单。
- 文档页 `/docs/components/drop-down` 的 8 项无头测试通过，覆盖 1440/390px 明暗主题、复制代码一致性、菜单右对齐、键盘、右键和缓存停用。
- 11 项独立导出与阅读应用无头测试通过，新增 1440→390→1024px 连续改变宽度后的 bottom-end 坐标检查。
- `docs:check`、90 项导出测试、文档 / 测试类型检查和 7 份 DropDown SFC 严格类型检查通过。
- 看板的完整 workbench 无头场景分别使用候选包、正式包通过，普通和减少动效下，常驻三个点按钮实际点击不会跳转，菜单与按钮右边缘对齐并位于按钮下方；应用类型检查和 `ui:check --check-versions` 通过。

`pnpm view @moubing/bing-ui@0.18.3 version dist-tags --registry=https://registry.npmjs.org/ --json` 确认版本和 latest 均为 0.18.3。组件库发布提交为 `ddd2ce6`，未推送或创建 Git 标签；本次文档和看板改动保留在工作区。已检查菜单展开及文档宽窄屏明暗主题截图，临时测试进程与产物在验证后清理。

## 历史验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/drop-down.md`，共享 API 包含 19 项菜单属性、12 项菜单项属性、9 个插槽条目、8 个事件条目、4 个实例方法，以及 10 个公开类型的 8 行说明。完整示例为基础菜单、资源右键菜单、菜单项和子菜单、受控状态与方法；命令为 `pnpm docs:export drop-down`。

- 保留 URL、原章节锚点、四个预览与控制区，新增公开类型章节。示例补齐导入、图标依赖、数据和处理函数，网页复制与 AI 导出使用同一份 SFC；图标使用已安装的 lucide-vue-next 1.0.0。
- 修正默认值、context 状态、主菜单键盘操作和事件时机。open 使用具名模型 v-model:open；null 为内部管理，受控值未同步时只发出请求。open/close 反映实际状态变化，after-enter/after-leave 反映动画完成。
- 右键上下文用 unknown 保存，访问前检查实际字段；支持鼠标右键与 Shift+F10，关闭动画结束后清空上下文。资源操作仅记录本地反馈；普通菜单项通过默认逻辑关闭，移除重复调用 close 的处理。
- 明确 shortcut 只展示，不注册键盘操作；active 只影响样式与 aria-current。click 回调中 preventDefault 可保留菜单并取消链接跳转，closeOnClick=false 本身不取消链接跳转。禁用链接渲染成按钮，_blank 链接默认补充 rel。
- 主菜单上下键、Home/End、循环或边界停留、跳过禁用项与 Escape 恢复触发器焦点已验证。0.5.3 子菜单的内部方向键没有接入主菜单处理，且带子菜单父项即使 closeOnClick=true 也不自动关闭，均记录为组件包限制，没有修改组件实现。
- 确认外部方法工具栏阻止自身 pointerdown 冒泡，避免外部关闭和 toggle 冲突；KeepAlive 页面停用时卸载预览实例并清空受控模型，消除 body 内的主菜单与子菜单残留，返回时保留配置。控制组使用唯一 Radio ID/name。
- 导出一致性和 48 项导出测试通过；文档、测试类型检查通过。20 个组件的 86 个导出 SFC 和 18 个阅读应用用例，共 104 个文件通过严格类型检查。
- 网页 7 项无头测试通过，覆盖 1440/390px 明暗主题、章节/API、四份代码复制、键盘开关、右键上下文、方法工具栏和缓存页面往返；四张页面布局截图已检查。
- 独立导出和阅读应用 8 项无头测试通过，覆盖四个完整示例、上下文切换和清空、子菜单选择、链接/禁用项、受控请求、无循环键盘导航、preventDefault、展示快捷键、hover 延迟与插槽、子菜单键盘限制及窄屏右下角定位。额外检查实际菜单与子菜单截图。
- 阅读应用由同一助手根据导出正文重组并核对，没有独立模型盲测。全站类型检查仍为原有 8 项错误，本轮无新增；未运行完整构建。测试进程已退出，临时截图与 trace 清理至回收站。
