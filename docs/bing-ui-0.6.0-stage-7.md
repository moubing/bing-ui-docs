# Bing UI 0.6.0 文档更新：第七阶段

日期：2026-09-12。对应[更新计划](bing-ui-0.6.0-update-plan.md)的新增 Cursor 阶段。

## 交付

新增 Cursor 正文、11 项 Props、插槽与状态参数、两个事件、元素属性及公开类型表。接入原有文档导航、Markdown 页面和 AI 导出，保留现有页面组织。

| 独立示例 | 内容 |
| --- | --- |
| basic | 自动识别按钮、输入、禁用和抓取，显示事件反馈，并保留原生区域 |
| states | 16 种状态、固定类型、画布大小和轮廓过渡时长，支持立即切换 |
| custom | 自定义 HTML 提示、点击热点、按压状态及目标信息 |
| follow | 保留原生光标的柔和跟随，提供时长和启停控制 |
| scope | 全局开关、两层局部实例及 Teleport 弹窗，说明 DOM 作用域优先级 |

网页直接使用五个完整 SFC，复制的代码包含演示控件及样式。全局体验默认关闭，所有示例在 KeepAlive 停用时卸载 Cursor，全局示例同时关闭弹窗与开关。站点未默认启用全局光标。

明确说明 CSS/禁用语义优先级、原生逃生属性、跨域样式读取、触摸与笔、强制颜色、减少动态效果、iframe/Shadow DOM/原生控件，以及插槽最多两份装饰内容的边界。热点不等于可点击区域，装饰提示不能代替控件可访问名称。
