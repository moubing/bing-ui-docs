# 0.18.2 下游联动验证

日期：2026-11-11。按 `bing-ui/docs/pending-consumer-updates.md` 同步 Slider（REQ-46）、Input（REQ-47）、Textarea（REQ-48）、Table（REQ-49/50）及 Button。先发布 0.18.0，联调发现 Table 的点击隔离问题后发布补丁，最终统一使用 0.18.2（发布提交 `bd7ccc6`）。npm 版本查询与 `latest` 一致。

## 同步内容

- 新增 16 个完整 Vue 示例，并通过薄包装在网页和 AI 导出中复用。现在共 40 个组件、228 个独立 SFC。
- Slider 补齐范围、刻度、气泡、尺寸、竖向、恢复默认、受控预览及公开 CSS 变量；范围模型和事件使用元组。
- Input 补齐 null 数字模型、失焦 / Enter 规整、密码选区、计数、加载和前缀拖动；现有示例和回调支持 `BingInputValue`。
- Textarea 补齐提交快捷键、组词隔离、清除撤销、稳定高度通知及默认 `clearable=false`。短标注与长说明分别展示 Enter / Ctrl+Enter。
- Table 增加键盘编辑、级联选择、远程全选、活动行、变高虚拟行、错误重试、骨架、固定列焦点及主题示例；说明 rowKey 序号、虚拟高度估计、远程缓存 rows 和 allPages/excludedKeys 边界。
- Button 补齐自然宽度、主动收缩与长文省略示例；快速开始的主题规范说明 `--bing-focus-ring`，Table 记录 15 个公开主题变量。
- 所有 AI 文档、manifest、摘要与 llms.txt 均由导出脚本生成。
