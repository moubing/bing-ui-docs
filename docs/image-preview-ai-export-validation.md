# ImagePreview 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/image-preview.md`，共享 API 包含 21 项属性、6 个图片项字段、5 个事件和 5 个公开类型。四个完整示例为基础打开、受控图库、工具栏行为和玻璃参数；命令为 `pnpm docs:export image-preview`。

- 保留原 URL、章节、控制区和四个预览，增加事件时机、焦点和生命周期说明。网页代码与 AI 导出共用完整 SFC，图片全部为内置 SVG，明确 900 × 560 / 520 × 720 的自然尺寸。
- 修复原页面直接访问数组项的两处类型错误；封面有空值判断。控制组使用独立 ID/name，缩略图按钮有明确名称。缓存页面停用时关闭并卸载四个预览，恢复滚动，切回后可再次打开。
- 核对 currentIndex 优先级、初始打开不发送 change、索引内部状态、列表过滤及缩短。阅读应用用可控请求验证：计数器和 change 先更新，旧图仍可见；等待期间下载 payload 对应实际旧图，不是目标索引。忽略索引更新不会阻止内部切图。
- 关闭先发送模型 false、再 close；忽略模型请求时仍保持打开，业务直接设 false 不补发。验证 Escape、遮罩、关闭按钮、正常焦点恢复、滚动锁只在打开时应用，以及没有 Tab 焦点循环。多实例没有统一滚动锁与快捷键协调，正文说明单活动实例约束。
- 验证缩放、旋转、拖动和重置；打开及重置固定回到 1 倍，即使配置区间不包含 1。隐藏工具栏也隐藏关闭按钮、计数器与加载提示，但保留快捷键；行为示例在三个关闭入口全禁用时提供业务退出按钮。
- 下载通过真实浏览器 download 事件核对文件名并清理文件；文档明确该通知不可取消，也不表示下载成功。玻璃默认值修正为 16 / 0.85 / 1.28，演示仍保留原配置 10 / 0.82；区分浮动控件背景与遮罩底色。
- 导出一致性、52 项导出测试、文档与测试类型检查通过。22 个组件的 95 个导出 SFC 加 20 个阅读应用，共 115 个文件通过严格类型检查。
- 网页 8 项用例通过，覆盖 1440/390px 明暗主题、原有章节/API、四份代码复制、初始索引、图库切换、关闭事件、缓存页面清理及退出兜底。四张文档布局截图和两张已打开预览的截图均已检查；名称调整后的相关用例已复测。
- 独立导出和阅读应用 8 项用例通过，覆盖四份示例、异步切图、下载载荷、关闭模型、列表缩短和空态、加载失败、缩放区间、隐藏工具栏与焦点边界。阅读应用由同一助手依据导出文档重组，没有独立模型盲测。
