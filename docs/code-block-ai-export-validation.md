# CodeBlock 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/code-block.md`，18 项属性、13 项尺寸配置及 3 个事件共用 `shared/docs/code-block.ts`。四个独立示例为基础、高亮和滚动、换行、调整尺寸；命令为 `pnpm docs:export code-block`。

## 迁移与修正

- 保留原 URL、章节、四个预览、行高亮和控制区；网页代码区与 AI 导出共用完整 SFC。
- 展示文本内置到示例，移除指向不存在文件的 raw 导入。字符串中的脚本结束标签采用 Unicode 转义，运行后展示和复制的仍是原文。
- Markdown 渲染器支持 DocsCallout；AI 导出将提示框展开成带标题的普通引用块，并补充导出回归测试。
- 明确 code 为必填字符串、代码仅展示而不执行、行号从 1 开始且范围包含首尾，以及无效行号不会高亮。
- 修正 copyError 说明：0.5.3 的 Clipboard API 拒绝后直接触发错误事件；仅 API 不存在时尝试兼容复制。补充自动主题与显式主题的区别。
- Select 事件按实际联合类型收窄；控制区 RadioGroup 使用唯一 ID/name 和显式子项。

## 验证

- 导出一致性、29 项导出测试、文档与测试类型检查通过；46 个导出 SFC 与 9 个阅读应用用例共 55 个文件通过严格类型检查。
- 网页 6 项浏览器测试通过，覆盖 1440/390px、明暗主题、章节/API、横向溢出、完整代码复制、原有行高亮、语言切换、提示框、换行及键盘调整尺寸。四种预览截图已人工检查。
- 独立示例 5 项浏览器测试通过，覆盖四个导出文件及阅读应用用例：复制原文和事件参数、闭区间选择、内部滚动、鼠标与键盘调整尺寸、复制失败反馈、无效行号、未知语言回退及切换语言恢复。
- 剪贴板检查兼容 Windows 的 CRLF；复制事件仍验证未经修改的原文。两套复制测试顺序运行，避免共用系统剪贴板产生干扰。
- 阅读应用用例由同一助手根据导出文档编写，未做独立模型盲测。全站类型检查仍有既有 15 项错误，无 CodeBlock 新增错误。
- 未运行完整构建；临时截图与测试进程已清理。
