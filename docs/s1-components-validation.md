# S1 组件文档验证记录

本次文档覆盖 BingTable、BingTableColumnControls、BingDialog、BingSplitPane 和 BingSlider。正式依赖已精确升级为 0.11.0，五页状态为 `verified`，文档修订 r1。

## 实现范围

- Table 的 remoteSort 保留服务器数据顺序，受控 null 能清空排序；与远程分页独立。
- ColumnControls 与表格内部共用实现，四组列模型可同时绑定多个分组，不依赖首个表格实例。
- Dialog 通过 height/maxHeight/maxWidth 和 header-addon 提供固定框架；默认规则兼容。
- SplitPane 保留偏好宽度，容器压缩不回写；拖动结束提交，取消不提交。
- Slider 连续更新数字，在指针、键盘结束时提交；支持原生触控和表单状态。
