# Select 迁移验证

## 0.17.0 正式包验证（2026-11-10）

已精确安装 npm 正式包，正文、API、预览和 AI 导出移除本轮能力的候选提示。Select / TreeSelect 文档页 19 项、独立示例与阅读应用 24 项无头用例通过，全部 90 项导出检查及 212 个 SFC 类型检查通过。详细范围见 [0.17.0 联动验证](bing-ui-0.17.0-validation.md)；下方候选说明仅记录发布前的历史状态。

## REQ-44 P0 候选验证（2026-11-10）

组件库候选源码新增默认开启的 `typeahead / highlightMatches`、option 插槽命中区间、面板内三态全选计数、标签动效和共享选择器外壳。当前发布依赖仍为 `0.16.0`；正文、API 和示例用“候选”标明新增能力，统一发版后再升级依赖和导出版本。

- 正文、API、网页与独立基础示例已同步；AI 导出由 `pnpm docs:export select` 生成，`pnpm docs:check select` 通过。
- `pnpm typecheck:docs`、`pnpm typecheck:tests` 和候选组件下的 8 个 Select SFC 严格类型检查通过。
- 候选组件下 Select / TreeSelect 文档页共 19 项、独立示例共 22 项无头用例完成验证。新增覆盖关闭时不改值、中文首字母定位、拼音命中标记及选项 Tab 顺序；既有搜索、范围全选、虚拟列表、弹窗、窄屏和主题场景保持正常。
- 两处测试首次失败分别来自旧 button 角色定位和多结果 locator 的严格模式；已修正为 combobox 与逐项 tabindex 检查，失败项单独复测通过。其余用例全量通过，未更改产品断言目标。
- 浏览器使用本地候选构建；未运行文档站完整构建、发布或部署。
- 后续批量标签性能优化的说明已同步正文与 AI 导出：大量选项直接收敛到可见标签和计数。性能、动画逐帧和 DOM 数量回归在组件库源码的 Storybook / 浏览器用例中执行，详见组件库 `docs/component-notes.md`；本次仅重新生成并检查文档导出。

## 早期迁移记录

适用 `@moubing/bing-ui 0.5.3`。七个完整 SFC 分别覆盖基础、多选、详情、虚拟列表、定位、尺寸与事件；命令为 `pnpm docs:export select`。六张 API 表覆盖 35 项属性、选项结构、3 个插槽、5 个事件、公开类型及滚动配置。

- 所有选项数据、受控状态和事件处理器完整内置。原先只显示模板且把布尔值写成字符串的搜索代码改为真实布尔配置；事件日志保留选择、关闭和清空顺序。
- 核对严格值比较、未知值、筛选范围内全选、禁用项与结果外值保留，以及全模型清空的区别。明确 clearable 只控制触发器清除按钮。
- 验证本地搜索范围、8 项搜索阈值、过滤后虚拟化阈值、末项键盘定位、详情插槽和定位边界。详情浮层标记 aria-hidden，正文提示不要承载必需信息或交互。
- 原页面引用的两个定位类型未从包入口导出，改为公开 Props 的索引类型。记录内部 listbox/option id 重复这一组件包限制；唯一触发器 id 无法修复内部 id。
- 网页离开缓存页面时卸载预览。搜索模式和虚拟模式控制区改为可换行，避免说明被挤成竖排。
- 68 项导出测试、导出一致性、文档/测试类型检查通过；127 个导出 SFC 与 28 个阅读应用，共 155 个文件严格类型检查通过。全站诊断从 6 项减至 4 项，余下为布局和 TreeSelect 的既有问题；未运行完整构建。
- 网页 7 项无头用例通过，检查宽窄明暗及窄屏面板截图。独立导出/阅读应用 8 项通过，包含真实筛选、选择、清空和按键。修正了测试中 searchbox 角色和详情面板类名，失败项复测通过。
- 阅读应用由同一助手依据导出文档重组，不是独立模型盲测。临时进程退出，截图及 trace 移入回收站。
