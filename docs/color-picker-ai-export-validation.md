# ColorPicker 迁移验证

适用 `@moubing/bing-ui 0.5.3`。四个完整 SFC 为基础配置、预设色板、独立尺寸和事件/实例方法。共享 API 补齐 id、玻璃模糊的字符串类型及实际默认值，包含 19 项属性、预设结构、6 个事件、4 个方法和 14 个公开类型。命令为 `pnpm docs:export color-picker`。

- 网页和 AI 导出使用同一套完整代码及内置色板。基础 v-model 适用于不透明颜色；事件示例改为读取 change.rgba，保存并回传透明度。
- 验证模型和 change.value 只返回六位 HEX；RGB 改变时普通 v-model 会丢失 alpha，读取完整载荷可以保留。默认展示/复制 HEX 是八位，格式选择只影响展示和复制，不是输出格式属性。
- 核对解析支持、非法输入回退、预设过滤及透明度、180ms 草稿提交、事件顺序、色域键盘操作、复制成功/失败与实例方法。说明 panelWidth 的数值解析、body 浮层、焦点行为及 FormItem 继承规则。
- 全部预览和控制区在缓存页面离开时卸载，清理面板、格式浮层和监听器；返回保留已提交颜色，未提交草稿取消。
- 导出一致性、64 项导出测试、文档/测试类型检查通过；28 个组件的 115 个导出 SFC 与 26 个阅读应用，共 141 个文件通过严格类型检查。全站仍有原有 6 项诊断，本组件无新增，未运行完整构建。
- 网页 7 项无头用例通过，四张明暗/宽窄布局和一张窄屏打开面板截图已检查，覆盖复制代码、配置状态、透明度和缓存页面清理。
- 独立导出/阅读应用共 8 项用例通过：首次 5 项通过，修正格式控件实际为 button、关闭遮挡后切换尺寸，以及暂停虚拟时钟后测精确延迟，余下 3 项复测通过。真实剪贴板得到八位 HEX；失败复制没有误发成功事件。阅读应用由同一助手根据导出文档重组，不是独立模型盲测。
- 临时浏览器与服务退出，截图及 trace 移入回收站。
