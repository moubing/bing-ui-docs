# Image 迁移验证

适用 `@moubing/bing-ui 0.5.3`。正文迁入 `content/components/image.md`，共享 API 包含 29 项属性、3 个插槽、5 个事件、15 个 Image 公开类型及 BingImagePreviewItem 的 6 个字段。五个完整示例为基础配置、占位回退、裁剪比例、预览图库和错误重试；命令为 `pnpm docs:export image`。

- 保留 URL、章节锚点、控制区与五个预览，新增公开类型和完整事件载荷。网页复制与 AI 导出共用 SFC，补齐组件/样式导入、SVG 生成函数、图片数据、状态和事件处理。
- 所有图片都内置，无外部图片服务或未提供的文件。故障示例使用故意损坏的 data URL；SVG 明确写入自然宽高，基础图为 900 × 560，竖图为 520 × 720。
- 核对原生尺寸属性、CSS 尺寸、srcset/sizes、加载优先级、跨域和 referrerPolicy。load.src 反映组件地址，不一定是浏览器经 srcset 选择的 currentSrc；事件中可读取真实 img.currentSrc。
- 明确主图失败、回退失败分别发送 error 与 isFallback；每轮只尝试一次回退。主图 loading 切到回退 loading 不重复发送状态，初始空地址保持 idle；仅修改 fallbackSrc 不自动重试。
- showLoading/showError 控制整个层及其自定义插槽，不取消加载或更改状态。placeholderSrc 可在 idle/loading/error 阶段保留；加载与占位层为 aria-hidden。retry 重建 img，重新尝试主图和回退，不保证绕过缓存。错误示例提供重试损坏数据和切换有效图片两种动作。
- 图库按钮使用各自的可访问名称；说明 figure 的按钮语义与 Enter/空格支持。previewItems 优先于单图配置，previewOpen 的 src 不等于图库当前项；禁用 preview 不清内部打开标记，重新启用可能再次打开，已通过阅读应用验证。
- 缓存页面停用时卸载预览实例，关闭内部图库并恢复滚动。切回页面后预览仍可正常使用；控制组使用唯一 Radio ID/name。
- 导出一致性、50 项导出测试、文档和测试类型检查通过。21 个组件的 91 个导出 SFC 和 19 个阅读应用用例，共 110 个文件通过严格类型检查。
- 网页 7 项无头测试通过，覆盖 1440/390px 明暗主题、章节/API、五份代码复制、裁剪控制、回退、错误重试恢复、图库索引与缓存页面滚动锁清理。保留原生 lazy；测试先滚到具体图片，再等待加载，避免只滚到长章节的中间。四张最终布局截图已检查。
- 独立导出和阅读应用 8 项无头测试通过，覆盖五个示例、预览键盘打开、原始尺寸、srcset 地址、加载/错误插槽开关、两次失败与重试、图库优先级和预览重新启用。测试图片请求由本地拦截控制，不依赖外部网络。
- 阅读应用由同一助手根据导出正文重组并核对，没有独立模型盲测。全站类型检查仍为原有 8 项错误，没有新增诊断；未运行完整构建。临时服务和浏览器已退出，截图与 trace 清理至回收站。
